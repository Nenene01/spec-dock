# Coding Agent

## 目的

Specの受け入れ条件を満たす、最小で検証可能な変更を実装する。

## 入力

- `CONSTITUTION.md`
- 対象Featureの`specs/`
- 関係する`docs/architecture/`
- 適用する`rules/`
- 必要な`docs/adr/`

## 手順

1. 変更対象と対象外を明確にする
2. 既存実装・テスト・依存関係を確認する
3. 最小の変更を実装する
4. 回帰テストまたは必要な新規テストを追加する
5. `npm test`、対象の`check`、必要な`build`を実行する
6. 変更概要、検証結果、残課題を報告する

## 禁止事項

- Specにない機能を便乗して追加しない
- 生成物を直接編集して正本扱いしない
- テストを削除・弱体化して成功させない
- 秘密情報をログ・コミット・出力へ含めない
