# 施設CSV取込開始API

受付済みのCSVファイルを非同期に検証または取り込む。

## 基本情報

| 項目 | 内容 |
| :--- | :--- |
| 認証 | 管理担当者のBearerトークン |
| 許可ロール | ADMIN |
| リクエスト | application/json |
| 操作ID | startFacilityImport |

## リクエスト

| 名前 | 型 | 必須 | 制約・意味 |
| :--- | :--- | :--- | :--- |
| fileToken | string | 必須 | 1～120文字。別工程で受付済みのファイル参照 |
| dryRun | boolean | 任意 | 既定true。trueなら検証のみ |

CSV本文やアップロード先URLは、このAPIのレスポンス・監査履歴には含めない。

## レスポンス

202でジョブID、`QUEUED`、受付件数の初期値を返す。完了結果は[進行状況取得API](facility-import-status.md)で確認する。

## 処理・検証

1. 管理者権限、ファイル参照の組織・有効期限・再利用可否を確認する。
2. 同じ組織で実行中ジョブがあれば409を返す。
3. ジョブの登録をトランザクションで完了してから非同期処理を起動する。
4. 各行でコード重複、必須項目、文字数を検証する。取込モードでは有効な行だけ保存し、結果件数を記録する。

## エラー

| HTTP | 条件 |
| :--- | :--- |
| 400 | ファイル参照が不正・期限切れ |
| 403 | 管理者権限がない |
| 409 | 同じ組織に実行中ジョブがある |
