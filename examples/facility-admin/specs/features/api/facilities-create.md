# 施設登録API

組織内で一意な施設コードを持つ下書き施設を登録する。

## 基本情報

| 項目 | 内容 |
| :--- | :--- |
| 認証 | 管理担当者のBearerトークン |
| 許可ロール | ADMIN / EDITOR |
| リクエスト | application/json |
| 操作ID | createFacility |

## リクエスト

| 名前 | 型 | 必須 | 制約 | 意味 |
| :--- | :--- | :--- | :--- | :--- |
| code | string | 必須 | 2～20文字、大文字英数字とハイフン | 組織内の施設コード |
| name | string | 必須 | 1～100文字 | 施設名 |

```json
{"code":"SITE-001","name":"中央施設"}
```

## レスポンス

201で作成した施設を返す。初期状態は `DRAFT`。`id` は新規採番され、作成日時を含む。

## 処理・検証

1. 組織IDと担当者の権限を確認する。
2. 入力を検証し、同一組織内の施設コード重複を調べる。
3. 施設を下書きで保存し、監査履歴に登録操作を記録する。この2件は同一トランザクションに含める。

## エラー

| HTTP | 条件 |
| :--- | :--- |
| 400 | 必須項目・文字種・文字数が不正 |
| 403 | 編集権限がない |
| 409 | 組織内の施設コードが重複する |
