# ADR

ADR（Architecture Decision Record）は、採用した設計と、その理由を残す場所です。

ADRには「何を実装するか」ではなく、「複数の選択肢からなぜこの構成を選んだか」を記録します。

## 形式

```text
# ADR-NNNN: decision title

## Status
proposed | accepted | superseded

## Context

## Decision

## Consequences
```
