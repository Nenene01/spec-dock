# 閉域共有できるStudio

## 目的

非エンジニアが、インターネットに接続できない社内ネットワークでも、許可されたブラウザから同じ仕様を閲覧できる。配置先は特定のクラウドや認証サービスに依存しない。

## 入力と結果

- 入力: SpecDockが読み取れるPrisma Schema、OpenAPI、Zod、Markdownと設定ファイル
- 結果: 静的ホストへ配置できる単一のStudioディレクトリ

## 受け入れ条件

1. ビルド後のStudioは、実行時に外部CDNやパッケージレジストリからライブラリを取得しない。
2. Markdown内のMermaid図は、Studioとともに配布したファイルを使って表示する。
3. HTML、スタイル、スクリプト、データ、アイコンは相対パスで参照でき、配置先のホスト名を固定しない。
4. Studioのデータファイルを含む配布物全体を、同じアクセス制御下に置ける。
5. 閲覧者にNode.js、Prisma、データベース接続を要求しない。
6. ビルド時のソース解析とブラウザでの閲覧を分離し、後者でプロジェクトの元ファイルを直接要求しない。

## 境界

ビルドにはNode.jsと依存パッケージの事前準備が必要。オフライン利用とは、**準備済みの成果物を配信・閲覧する段階**で外部サービスへの接続を要しないことを指す。ビルド自体を完全オフラインで行うには、依存パッケージの社内ミラーや事前キャッシュが別途必要。

Studioには認証・認可、IP制限、VPN管理、機密情報の自動除去を実装しない。配置先の保護と公開前の内容確認は運用側の責任とする。Markdownに記載された外部リンクのリンク先までは、オフライン閲覧を保証しない。
