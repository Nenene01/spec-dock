# Studio閲覧体験

## 目的

Prisma、Zod、OpenAPI、Markdownを知らない閲覧者でも、業務の説明からAPI・データへ進み、必要に応じて定義元を確認できる。

## 利用者の問い

- 何ができるシステムか → Document
- 操作すると何が起こるか → API
- どんな情報を扱うか → データ型、データモデル、ER図
- 表示内容の根拠はどこか → 対応するソースとファイル

## 受け入れ条件

1. 概要画面は上記の問いから実際の項目へ直接進める。空の一覧画面へ誘導しない。
2. ソースのパスや件数は主な導線より控えめに表示し、必要な場合に確認できる。
3. 詳細画面は日本語の見出しと一貫した文字組みを用い、狭いペインでも表を読める。
4. キーボード操作時に、現在フォーカスしている項目が見える。
5. すべての閲覧情報は既存ソースから生成した中間モデルを使い、画面専用の正本を増やさない。
6. APIを参照するDocumentから、対応するAPIへ同一ペイン内で移動できる。先頭見出し・概要が画面ヘッダーと重複する場合、表示モードでは繰り返さず、Codeモードでは原文を保持する。
7. Studioには錨をモチーフとしたfaviconを設定し、生成したサイトを配信したときも表示できる。

## 対象外

- ソースの編集
- AIによる解釈・要約の自動生成
- プロジェクト横断検索
